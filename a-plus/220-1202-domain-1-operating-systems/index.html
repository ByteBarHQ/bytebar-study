CompTIA A+ (220-1202) Domain 1.0: Operating Systems — Explained

Domain 1.0 is the biggest 1202 domain: Windows editions and features, installing and upgrading, the command-line tools technicians live in, and the utilities that keep systems healthy. The daily craft of desktop support.

Exam: 220-1202 · weight ~31% · Free study preview from ByteBar

Windows editions and features

  • Editions — Home (consumers, no domain join, no BitLocker), Pro (domain join, BitLocker, Remote Desktop host, Hyper-V), Pro for Workstations / Enterprise (volume licensing, advanced management). Match the edition to the need — Home can't join a domain, full stop.
  • Feature differences that matter — BitLocker (full-disk encryption: Pro+), Remote Desktop hosting (Pro+; Home can only be a client), Group Policy (Pro+), Windows Sandbox (Pro+).
  • macOS and Linux awareness — know they exist in mixed environments: macOS (Disk Utility, Time Machine, Terminal), Linux (distributions, package managers, the terminal-first workflow). Aim for literacy, not mastery.
  • 32-bit vs. 64-bit — 64-bit addresses effectively unlimited RAM; 32-bit caps near 4 GB. Modern installs are 64-bit; 32-bit survives only in legacy corners.

Installation and upgrades

  • Install types — clean install (wipe and start fresh — the fix for deeply broken systems), in-place upgrade (keep files/settings/apps — faster, carries cruft), repair installation (fix system files, keep everything).
  • Boot methods — USB/DVD media, network (PXE), or recovery partition. UEFI vs. legacy BIOS: UEFI is modern (GPT disks, Secure Boot); know which mode the system uses before installing.
  • Partitioning — GPT (modern, UEFI, huge disks) vs. MBR (legacy, 2 TB limit). The installer's choice must match the firmware mode.
  • Post-install checklist — drivers, updates, antivirus, hostname/domain join, user accounts, backups configured. An install isn't done at the desktop.
Clean install = fresh start. In-place upgrade = keep everything, keep the problems. GPT + UEFI is the modern pairing; MBR + BIOS is legacy.

Command-line tools and utilities

  • Disk tools — chkdsk (file system errors), diskpart (partition management), format (prepare a volume). Check the disk before blaming the OS.
  • Network tools — ipconfig (/release, /renew, /flushdns), ping, tracert, netstat (connections and listening ports), nslookup. The connectivity ladder: address → gateway → DNS → remote.
  • System tools — sfc /scannow (repair protected system files), dism (service the Windows image itself), tasklist/taskkill, shutdown, gpupdate (refresh Group Policy).
  • GUI utilities — Task Manager (performance, startup impact), Disk Management, Device Manager (driver issues — yellow bangs), Event Viewer (the logs that explain the crash), System Configuration (msconfig: boot and startup control).
  • Recovery environment — WinRE: Startup Repair, System Restore, Safe Mode. When Windows won't boot normally, WinRE is the workshop.

Try it: 4 sample questions

Sample questions to check your understanding of this domain. Answers and full reasoning are tucked under each one.

1. A workstation needs to join the company domain and use BitLocker. It currently runs Windows 11 Home. What is required?

  1. A. A. Nothing — Home supports both
  2. B. B. An edition upgrade to Pro (or higher) — Home can't join domains or run BitLocker
  3. C. C. A registry tweak
  4. D. D. A new motherboard
Show answer & reasoning

B. Domain join, BitLocker, Remote Desktop hosting, and Group Policy are Pro-and-up features — Home excludes them by design. No setting unlocks them; the edition must change. "Can't join the domain on Home" is a rite-of-passage support call.

2. System files are suspected corrupt after a bad update, but the OS still boots. Which tool repairs protected Windows files?

  1. A. A. chkdsk
  2. B. B. sfc /scannow — scans and repairs protected system files
  3. C. C. ipconfig /flushdns
  4. D. D. diskpart clean
Show answer & reasoning

B. SFC (System File Checker) verifies protected OS files against known-good copies and repairs them. chkdsk (A) fixes file system errors, not file content; if SFC can't repair, DISM services the underlying image SFC draws from. diskpart clean (D) would wipe the disk — catastrophically wrong here.

3. A user reports "no internet." The technician's first three command-line checks should be:

  1. A. A. format, diskpart, chkdsk
  2. B. B. ipconfig (do I have an address?), ping gateway (is the LAN up?), ping/nslookup outward (is it DNS or real connectivity?)
  3. C. C. sfc, dism, gpupdate
  4. D. D. Reinstall Windows immediately
Show answer & reasoning

B. Troubleshoot in layers: address (ipconfig — APIPA 169.254.x.x means DHCP failed), then local path (ping the gateway), then name vs. connectivity (nslookup/ping by name vs. IP splits DNS failures from real outages). Each answer narrows the next step. Never reinstall before diagnosing.

4. A second-hand laptop must be wiped completely before redeployment, including all partitions. Which approach?

  1. A. A. Delete files from the desktop
  2. B. B. Clean install: boot install media, delete all partitions in setup, install fresh on unallocated space
  3. C. C. In-place upgrade
  4. D. D. System Restore
Show answer & reasoning

B. Only a clean install with partition deletion guarantees removal of everything — old OS, recovery partitions, hidden data. Deleting files (A) leaves the OS and everything else; in-place upgrade (C) preserves; System Restore (D) rolls back settings, not ownership. Redeployment = clean slate.
